# timeslottr

timeslottr turns working hours into bookable time slots. Use it to skip breaks,
remove existing bookings, and find times when everyone on a team is free.

It is a TypeScript library with no runtime dependencies. It handles timezones
and daylight-saving changes using the platform's `Intl` API. You provide the
calendar data, storage, and booking UI.

## Choose the function for your task

| I want to… | Use |
| --- | --- |
| Generate slots for one day or time window | [`generateTimeslots`](/api/generation#generatetimeslots) |
| Apply working hours across several days | [`generateDailyTimeslots`](/api/generation#generatedailytimeslots) |
| Offer slots around existing bookings or several people's calendars | [`generateAvailableTimeslots`](/api/generation#generateavailabletimeslots) |
| Subtract busy time or find shared free time without generating slots | [`subtract` and `intersect`](/api/availability) |

## Generate your first slots

Generate 30-minute slots for a single day, skipping a lunch break:

```ts
import { generateTimeslots } from 'timeslottr'

const slots = generateTimeslots({
  day: '2024-01-01',
  timezone: 'America/New_York',
  range: { start: '09:00', end: '17:00' },
  slotDurationMinutes: 30,
  excludedWindows: [{ start: '12:00', end: '13:00' }],
})

console.log(slots.length) // 14 slots: 9 to 12 and 1 to 5, every 30 minutes
console.log(slots[0].start.toISOString()) // '2024-01-01T14:00:00.000Z'
console.log(slots[0].end.toISOString())   // '2024-01-01T14:30:00.000Z'
```

Each slot is a `Timeslot` with an inclusive `start`, an exclusive `end`, and some
`metadata`. Start and end are real `Date` objects. In this example, 09:00 in
New York is 14:00 UTC. The `Z` in the output means UTC; it does not mean the
configured timezone was ignored.

These fixed-date examples work whenever you run them. Past dates are included
unless you enable a [booking window](/docs/scheduling#booking-windows).

## Find a time that works for a team

Take a base schedule, remove what is already booked, and keep only the windows
where everyone is free.

```ts
import { generateAvailableTimeslots } from 'timeslottr'

const slots = generateAvailableTimeslots({
  day: '2024-01-01',
  timezone: 'America/New_York',
  range: { start: '09:00', end: '17:00' },
  slotDurationMinutes: 30,
  busy: [{ start: '12:00', end: '13:00' }], // already-booked
  participantsBusy: [
    [{ start: '09:00', end: '10:00' }], // Alice
    [{ start: '16:00', end: '17:00' }], // Bob
  ],
})
// 10 slots: 10:00–12:00 and 13:00–16:00 in America/New_York
```
